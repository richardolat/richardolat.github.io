# The Olatunde Record

Portfolio of press statements, news coverage and radio appearances by Richard Olatunde.

## Adding content
Edit `data.js`. Copy any block in `statements`, `stories` or `radio`, change the details, commit. The site sorts by date automatically.

Radio videos: upload the `.mp4` into `media/` (under 100 MB each) and point `video:` at it. For a YouTube video use `youtube: "VIDEO_ID"` instead.
